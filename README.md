# CoffeeNet ERP — Система управління мережею кав'ярень

Даний проєкт є курсовою роботою з дисципліни "Проектування та розробка інформаційних систем".

## 🚀 Функціональні можливості

- **Адміністратор:** Керування користувачами (схвалення заявок франчайзі), додавання кавомашин, моніторинг телеметрії, обробка запитів на обладнання.
- **Франчайзі:** Реєстрація (потребує схвалення), замовлення інгредієнтів, моніторинг власних апаратів, замовлення нових кавомашин.
- **Технік:** Отримання та виконання завдань на обслуговування, перегляд стану датчиків апаратів.

## 🛠 Технологічний стек

- **Backend:** Node.js, Express
- **Database:** PostgreSQL
- **Frontend:** HTML5, Bootstrap 5, Chart.js, FontAwesome
- **DevOps:** Docker, Docker Compose, node-pg-migrate

## 📦 Інструкція із запуску

Для запуску проєкту однією командою необхідно мати встановлений Docker.

1. **Клонуйте репозиторій:**
   ```bash
   git clone https://github.com/Skitrow/kursova-coffee.git
   cd kursova-coffee
   ```

2. **Запустіть Docker Compose:**
   ```bash
   docker-compose up --build
   ```

3. **Міграції:**
   Міграції застосовуються автоматично при старті контейнера. Якщо потрібно виконати їх вручну:
   ```bash
   docker-compose exec backend npm run migrate:up
   ```

4. **Відкрийте застосунок:**
   Перейдіть за адресою [http://localhost:5000](http://localhost:5000)
