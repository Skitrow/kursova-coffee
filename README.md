# CoffeeNet ERP - Курсова робота

Цей репозиторій містить вихідний код повноцінної ERP/CRM системи для управління мережею кав'ярень самообслуговування (вендинг). 

## 🌟 Останні оновлення (Новий функціонал)
- **Реєстрація франчайзі:** Нові користувачі можуть подати заявку на реєстрацію як франчайзі. Адміністратор повинен схвалити її в панелі керування.
- **Управління користувачами:** Адміністратор має повноцінну сторінку для зміни статусу (Схвалено, Очікує, Відхилено) та видалення користувачів.
- **Керування кавомашинами:**
  - Адміністратор може напряму додавати нові кавомашини в систему.
  - Франчайзі мають можливість робити **заявки на нові апарати**, які адміністратор розглядає (схвалює або відхиляє) в розділі "Заявки на апарати".

## 🛠 Технологічний стек
- **Backend:** Node.js, Express.js
- **Frontend:** HTML5, CSS3, JavaScript, Bootstrap 5 (SPA)
- **Database:** PostgreSQL (запускається локально через Docker)
- **Інфраструктура:** Docker, Docker Compose
- **Міграції:** node-pg-migrate

---

## 🚀 Інструкція із запуску (Docker)

Проєкт повністю контейнеризований і не вимагає локального встановлення Node.js або PostgreSQL. 

1. Склонуйте репозиторій:
   ```bash
   git clone https://github.com/Skitrow/kursova-coffee.git
   cd kursova-coffee
   ```

2. Запустіть проєкт однією командою:
   ```bash
   docker-compose up -d --build
   ```
   *(Параметр `-d` запускає контейнери у фоновому режимі).*

---

## 🗄 Міграції бази даних

База даних запускається в контейнері порожньою. Щоб система працювала, необхідно виконати міграцію, яка створить таблиці та базові облікові записи.

Виконайте команду для накатування міграцій всередині контейнера бекенду (може знадобитись кілька секунд після запуску БД, щоб база ініціалізувалась):
```bash
docker-compose exec backend npm run migrate:up
```
