# CoffeeNet ERP - Курсова робота

Цей репозиторій містить вихідний код повноцінної ERP/CRM системи для управління мережею кав'ярень самообслуговування (вендинг). 

## 🛠 Технологічний стек
- **Backend:** Node.js, Express.js
- **Frontend:** HTML5, CSS3, JavaScript, Bootstrap 5 (SPA)
- **Database:** MongoDB (запускається локально через Docker)
- **Інфраструктура:** Docker, Docker Compose
- **Міграції:** migrate-mongo

---

## 🚀 Інструкція із запуску (Docker)

Проєкт повністю контейнеризований і не вимагає локального встановлення Node.js або MongoDB. 

1. Склонуйте репозиторій:
   ```bash
   git clone https://github.com/Skitrow/kursova-coffee.git
   cd kursova-coffee
   ```

2. Запустіть проєкт однією командою:
   ```bash
   docker-compose up -d --build
   ```
   *(Параметр `-d` запускає контейнери у фоновому режимі).*

---

## 🗄 Міграції бази даних

База даних запускається в контейнері порожньою. Щоб система працювала, необхідно виконати міграцію, яка створить початкові колекції та облікові записи.

Виконайте команду для накатування міграцій всередині контейнера бекенду:
```bash
docker-compose exec backend npm run migrate:up
```
